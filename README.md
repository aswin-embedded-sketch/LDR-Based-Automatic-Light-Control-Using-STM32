# LDR-Based-Automatic-Light-Control-Using-STM32
This project demonstrates LDR sensor interfacing with an STM32 microcontroller to detect changes in light intensity. The LDR provides an analog voltage to the STM32 ADC, and the microcontroller controls an LED based on the detected light level. The project was developed and tested using STM32CubeIDE and Proteus simulation.
