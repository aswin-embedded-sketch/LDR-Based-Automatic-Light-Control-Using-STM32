# LDR Based Automatic Light Control Using STM32

## Overview

This project demonstrates an automatic light control system using an LDR (Light Dependent Resistor) and the STM32F446RE microcontroller.

The LDR detects the intensity of surrounding light. The analog voltage generated by the LDR circuit is read by the STM32 using its built-in ADC. Based on the detected light intensity, the STM32 automatically controls an LED.

The LED is turned ON when the surrounding light level is low and turned OFF when sufficient light is detected.

---

## Components Used

- STM32F446RE Nucleo Board
- LDR (Light Dependent Resistor)
- Resistor
- LED
- Current Limiting Resistor
- Jumper Wires
- Breadboard

---

## Features

- Detects surrounding light intensity using an LDR
- Uses the STM32 built-in ADC
- Converts analog sensor input into a digital value
- Automatically controls an LED based on light intensity
- Demonstrates ADC and GPIO interfacing
- Simulated using Proteus
